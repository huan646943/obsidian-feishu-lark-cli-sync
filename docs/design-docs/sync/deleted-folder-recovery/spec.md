# 已删除 Wiki 目录缓存恢复

## 背景与目标

插件直接使用目录缓存，飞书删除目录后，新建发布继续传入旧父节点而失败。按已确认方案，复用 Wiki 缓存前读取节点，只在明确返回 `131012` 时自动重建插件生成的目录。

## 接口与实现

- 修改 `src/main.ts`，接口签名保持不变。CLI 错误保留结构化业务错误码，不通过文字匹配判断删除。
- 对缓存 Wiki/个人文档库节点执行 `wiki +node-get`；有效则复用，无权限、网络异常、普通不存在等错误原样上抛。
- 已删除时仅清理同一个缓存键及以 `/` 分隔的子目录键，保留兄弟目录和其他发布位置。持久化缓存失效，按原路径创建并持久化新绑定，继续解析子目录。
- Drive 目录沿用既有流程；用户配置的根位置不进入自动重建范围。
- 当前修改只交付插件，保留用户现场的失效缓存以供用户测试恢复。
